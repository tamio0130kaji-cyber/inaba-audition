# YouTube 参考チャンネル リサーチ＆スコアリング

開設1年以内で初動から反響が出ているチャンネルを、**YouTube Data API v3** で自動採点するための Google Apps Script ツール。
要件定義スプレッドシートの5軸をそのまま判定ロジックに落とし込んでいる。

## 何ができるか

A列に貼ったチャンネルURL/ID/@ハンドルを一括で取得し、「結果」シートに採点表を生成する。

| 判定軸 | 採点内容 |
|---|---|
| 軸1 鮮度 | 開設1年以内 かつ 直近30日以内に投稿 |
| 軸2 初動※ | 月あたり登録者増（近似）が基準以上 |
| 軸3 エンゲージ | 再生÷登録者 ≥15% / エンゲージ率 ≥3% / 平均コメント ≥10 |
| 軸4 規模 | 登録者100万以下 |
| 総合判定 | 全軸クリアで「◎ 参考候補」 |

## セットアップ

1. 採点用の Google スプレッドシートを新規作成
2. **拡張機能 > Apps Script** を開き、`Code.gs` の内容を貼り付けて保存
3. [Google Cloud Console](https://console.cloud.google.com/) で **YouTube Data API v3** を有効化し、APIキーを発行
4. Apps Script の **プロジェクトの設定 > スクリプト プロパティ** に追加
   - キー: `YOUTUBE_API_KEY`
   - 値: 発行したAPIキー
5. シートのA1に `channel` と入力し、A2以降にチャンネルを縦に貼る
   （`https://www.youtube.com/@xxxx` / `https://www.youtube.com/channel/UC...` / `UC...` / `@xxxx` いずれも可）
6. 再読み込みで現れるメニュー **「YT リサーチ」> 「全行を採点」** を実行（初回は権限承認）

## 取得精度と限界

| 指標 | 精度 |
|---|---|
| 開設日 / 最終投稿日 / 動画本数 / 登録者数 / 総再生数 | ✅ 正確（API公式値） |
| 直近動画の平均再生・いいね・コメント | ✅ 正確（直近15本のサンプル平均） |
| **「開始3ヶ月での登録者数」等の過去スナップショット** | ⚠️ API非対応 |

YouTube Data API は**現在値のみ**を返し、過去の登録者推移は取得できない。
そのため軸2「初動の反響」は `現在の登録者数 ÷ 開設からの月数` で**初動速度を近似**している（結果列に ※ 印）。

## API クォータ

1日10,000ユニットの無料枠。1チャンネルの採点で概ね5〜7ユニット消費するため、1日1,000件以上が採点可能。

## 基準値の変更

`Code.gs` の `CRITERIA` オブジェクトを編集すれば閾値を変更できる。
要件定義スプレッドシートと数値を必ず一致させること。
